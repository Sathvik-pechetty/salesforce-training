
What is LWC?

Lightning Web Components (LWC) is Salesforce's modern framework for building fast and reusable user interface components using HTML, JavaScript, and XML.

Why Salesforce Uses LWC

Salesforce uses LWC to provide a modern, high-performance, component-based UI architecture that follows web standards and improves application performance.

Difference between frontend and backend?
   | Frontend                        | Backend                               |
| ------------------------------- | ------------------------------------- |
| User interface (what users see) | Business logic and data processing    |
| Uses HTML, CSS, JavaScript, LWC | Uses Apex, databases, APIs            |
| Handles user interactions       | Handles calculations and data storage |

 What is a component?

A component is a reusable part of a user interface that performs a specific function. Examples include buttons, forms, dashboards, and navigation bars.

Reflection: Why do modern enterprise systems use component-based UI architecture?

Modern enterprise systems use component-based UI architecture because components are reusable, maintainable, scalable, and help teams develop applications faster while ensuring a consistent user experience.
